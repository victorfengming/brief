## 摘要

超过 JavaScript 安全整数范围的订单号，如果在 JSON 链路中被解析为 Number，就可能丢失精度，导致跨端查询或状态关联使用错误的标识。本文将介绍如何在存储、接口、前端和日志之间统一字符串契约，并通过边界值验证避免先发生精度丢失再转为字符串的问题。
